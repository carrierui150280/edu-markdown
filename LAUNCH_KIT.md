## Short pitch

`edu-markdown` is a local-first CLI that converts web pages, HTML, TXT, Markdown, DOCX, and text-based PDFs into clean Markdown with YAML front matter. It is built for teachers, content operators, and AI workflow builders who need readable source material instead of raw document dumps.

I just open-sourced `edu-markdown`, a small CLI tool for turning mixed teaching materials into clean Markdown with metadata.

正文:

最近把一个自己在用的小工具整理出来开源了: `edu-markdown`

它不是大而全的平台，而是一个本地优先的 CLI，专门解决一个很窄的问题:
把网页、HTML、TXT、Markdown、DOCX、text-based PDF 这类混杂资料，转成可读、可追溯的 Markdown，并保留 YAML front matter。

我主要把它用在两类场景:
- 教学资料整理
- 给后续搜索 / chunking / RAG / 其他 AI 流程准备干净输入

当前版本是 `v0.1.0`，已支持:
- URL 转 Markdown
- 本地 `html` / `txt` / `md`
- `docx`
- 有文字层的 `pdf`
- `convert-dir` 递归批量转换

我暂时没有把它往“大而全文档平台”做，第一步只想把输出质量和流程边界做扎实。

如果你也在折腾:
- 教学资料知识库
- Markdown-first 归档
- 本地优先的 AI 预处理

欢迎提 issue 或直接拍砖。下一步我现在最犹豫的是先补 OCR，还是先做 chunked JSON export。

https://github.com/carrierui150280/edu-markdown
