# Outreach Plan

## Goal

Get the first real views, stars, and feedback without overselling the project.

## Wave 1: first 48 hours

1. GitHub repo polish
   - keep the repo description as:
     `Turn teaching materials and web articles into clean Markdown with metadata.`
   - keep topics set
   - use the release link in outreach
   - keep the README focused on the narrow use case

2. First English post
   - use the short X-style copy from `LAUNCH_KIT.md`
   - goal: quick clicks and first outside feedback

3. First Chinese post
   - use the Chinese post or Chinese short plain-text copy from `LAUNCH_KIT.md`
   - preferred angle:
     - narrow tool
     - practical workflow cleanup
     - local-first
     - useful for teachers and AI workflow builders
   - post where teachers, AI workflow tinkerers, or indie builders actually read

4. One developer community post
   - best fit:
     - Hacker News
     - Reddit
     - V2EX
     - a focused Python or AI tools community
   - angle:
     - narrow workflow tool
     - local-first
     - useful output
     - not startup hype

## Recommended posting order

1. GitHub profile and repo polish
2. One English post
3. One Chinese post
4. One developer community post
5. Only then start reacting to feedback

## Copy to link most often

- Repo:
  `https://github.com/carrierui150280/edu-markdown`
- Release:
  `https://github.com/carrierui150280/edu-markdown/releases/tag/v0.1.0`

## What to watch

- stars
- repo traffic
- clones
- first issue or question
- whether people ask for OCR or chunk export first

## Reply policy

- answer every real question fast
- if multiple people ask for the same thing, turn it into an issue or roadmap item
- do not add major features before the first real outside reactions
- keep the Chinese and English framing aligned:
  - narrow tool
  - clean Markdown
  - explicit metadata
  - local-first workflow utility

## First feedback threshold

Once one of these happens, adjust the roadmap:

- 3 or more stars from unrelated users
- 1 real issue
- 2 or more people ask for the same missing feature
- traffic clearly spikes after one specific post
